# futmoleque-api

API do FutMoleque, o app para organizar peladas.

- Stack: C# com .NET e PostgreSQL
- O código da solução entra no card S0.06 (estrutura em camadas)

## Como contribuir

Leia o [CONTRIBUTING.md](CONTRIBUTING.md) antes do primeiro commit. Depois de clonar, ative o hook de commit:

```bash
git config core.hooksPath .githooks
```
